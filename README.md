# Hasti Campaign Brief

AI-powered content and campaign planning dashboard.

A modern dashboard for planning campaigns, monitoring performance, and turning marketing insights into action. This project gives you a polished executive-view interface for content strategy and campaign management.

## Features

- AI-inspired campaign overview dashboard
- KPI cards for growth metrics
- Pipeline status tracking
- Recommendations panel
- Editorial calendar planning view
- Responsive layout for desktop and tablet/mobile screens

## Tech stack

- Vite
- Vanilla HTML, CSS, and JavaScript

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
